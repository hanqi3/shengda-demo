# 声搭 · AI短视频配乐助手（交互 Demo）

产品经理测评原型。单文件 HTML，无需安装、无需联网、不调用付费服务。

## 打开方式

- 在线：GitHub Pages 链接 `https://<用户名>.github.io/shengda-demo/`
- 本地：下载 `index.html`，双击用 Chrome / Edge 打开

## 这是什么

为不具备音乐专业知识的短视频创作者设计：为一条 30—60 秒视频找到合适的背景音乐。

三个核心界面，同一界面的不同状态覆盖异常路径：

1. **描述需求**：视频内容、情绪预设、时长、有无口播、补充要求（纯音乐默认勾选）
2. **等待与试听**：等待 30—90 秒的预期与已等待时间；两首候选对照试听、拖动进度、确认可用
3. **获取配乐**：时长/格式/来源回显、下载、返回比较

页面右下角「评审演示」面板可切换六种生成情境：正常、时长不符与疑似人声、风格不符、部分失败、全失败、超时。
「喜欢这首，但想改开头」会先说明能力边界，再保留旧版并生成新版本。

## 模拟声明

生成结果、示例音频（程序合成，16kHz 单声道 WAV）、时长校验与人声标记均为模拟，不是真实模型的输出，也不代表已具备人声检测能力。
页面顶部与页脚常驻「模拟生成 / 模拟校验」标记。

## 范围

- 演示：需求表达 → 等待反馈 → 两首对照试听 → 确认下载 → 异常恢复
- 不包含：真实模型接入、视频内容自动理解、精确局部重生成、人声消除、自动卡点与导出
